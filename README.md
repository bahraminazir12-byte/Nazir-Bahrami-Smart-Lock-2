# NAZIR BAHRAMI SMART LOCK

Android QR identity demo.

## GitHub Actions
1. Upload/extract this project into the repository root.
2. Open GitHub Actions.
3. Run "Build Nazir Bahrami Smart Lock APK".
4. Open the successful run.
5. Download "Nazir-Bahrami-Smart-Lock-APK".

The app opens the camera QR scanner and checks the scanned text against:
NAZIR-BAHRAMI-2024

This is an in-app QR identity demo. It does not unlock Android's system lock screen, bypass a PIN/pattern/password, or change device security settings.
